# Actividad: CPU, RAM y almacenamiento

## Actividad: el viaje de los datos dentro del ordenador

### Objetivo

Crear una presentación interactiva y animada que explique la función de tres componentes fundamentales de un ordenador y el recorrido que siguen los datos entre ellos.

Puedes utilizar **Genially** o **Canva**. Se recomienda **Genially** para esta actividad porque permite mostrar información al pasar el ratón sobre un elemento. Canva es una buena alternativa para crear animaciones, pero sus opciones de interacción al pasar el ratón pueden ser más limitadas.

### Diapositiva 1: los tres componentes principales

Diseña una diapositiva que incluya imágenes o ilustraciones de estos componentes:

1. **CPU o procesador**
2. **Memoria RAM**
3. **Almacenamiento interno**, como un SSD o un disco duro HDD

Al pasar el ratón por encima de cada imagen, debe aparecer una breve explicación con sus características más importantes:

* **CPU:** ejecuta instrucciones, realiza cálculos y coordina el funcionamiento del ordenador.
* **RAM:** guarda temporalmente los datos y programas que se están utilizando; es rápida y volátil.
* **Almacenamiento:** conserva los programas y archivos aunque se apague el ordenador; puede ser un SSD o un HDD.

La diapositiva debe permitir identificar fácilmente cada componente y distinguir su función de la de los demás.

### Diapositiva 2: el recorrido de los datos

En una segunda diapositiva, representa mediante una animación cómo se mueve la información cuando se ejecuta un programa.

1. Los datos y el programa comienzan almacenados en el **SSD o HDD**.
2. Al abrir el programa, una copia de esos datos pasa del almacenamiento a la **memoria RAM**.
3. Mientras el programa funciona, la **CPU** y la **RAM** intercambian datos e instrucciones continuamente. Deben aparecer flechas o elementos en movimiento en ambos sentidos.
4. Cuando se guardan cambios o se cierra el programa, los datos necesarios vuelven desde la **RAM** al almacenamiento.

Representa los datos como elementos binarios, por ejemplo, grupos de `0` y `1`, paquetes de datos o pequeños bloques que se desplacen entre los componentes. La animación debe dejar claro el sentido del recorrido y el motivo de cada desplazamiento.

### Entrega y comprobación

Comparte el enlace a tu presentación y comprueba antes de entregarla que:

* la información aparece al pasar el ratón sobre cada componente;
* la segunda diapositiva contiene elementos en movimiento;
* se distinguen los intercambios entre la CPU y la RAM;
* se explica cuándo los datos vuelven al almacenamiento;
* el texto se puede leer y los elementos están ordenados.
