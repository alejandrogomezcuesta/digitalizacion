# Instalar aplicaciones

En Windows 11 hay dos formas habituales de instalar aplicaciones:

- **Desde Microsoft Store:** abre la tienda, busca una aplicación y pulsa **Obtener** o **Instalar**. La tienda gestiona la descarga y las actualizaciones.
- **Descargando y ejecutando un instalador:** descarga el archivo desde la página oficial de la aplicación y ábrelo para iniciar el asistente de instalación. Comprueba siempre que la página sea la oficial y lee cada pantalla antes de continuar.

En esta práctica instalarás dos aplicaciones desde Microsoft Store y cuatro mediante descarga. Realiza todas las tareas con ventanas. Trabaja en la máquina virtual de Windows y no desactives las protecciones del sistema.

**Solo tienes que entregar dos capturas:** una con todas las aplicaciones instaladas y otra que demuestre que VLC se ha desinstalado. No hagas capturas de cada instalación.

## Instalar Spotify desde Microsoft Store

1. En **Microsoft Store**, busca `Spotify`.
2. Selecciona la aplicación y pulsa **Obtener** o **Instalar**.
3. Espera a que termine la instalación; no es necesario iniciar sesión.

## Instalar TeamViewer mediante descarga

1. Abre el navegador y visita la [página oficial de descarga de TeamViewer](https://www.teamviewer.com/download/windows/).
2. Descarga la versión para Windows y abre el archivo descargado desde el navegador o desde la carpeta **Descargas**.
3. Sigue el asistente de instalación con las opciones predeterminadas.
4. Cuando termine, comprueba que TeamViewer aparece en **Inicio** o que se abre correctamente. No inicies una conexión, no compartas ningún código o contraseña y no configures el acceso desatendido.

## Instalar 7-Zip mediante descarga

1. Visita la [página oficial de 7-Zip](https://www.7-zip.org/).
2. Descarga el instalador adecuado para tu equipo. En la mayoría de los ordenadores del aula será **64-bit x64**; si tienes dudas, consulta **Configuración > Sistema > Acerca de > Tipo de sistema**.
3. Abre el archivo descargado y pulsa **Install** en el asistente.
4. Comprueba que 7-Zip aparece en **Inicio**.

## Instalar Google Chrome mediante descarga

1. Visita la [página oficial de Google Chrome](https://www.google.com/chrome/).
2. Pulsa **Descargar Chrome** y abre el instalador descargado.
3. Sigue los pasos de instalación. No hace falta iniciar sesión ni importar datos del navegador.
4. Comprueba que Google Chrome aparece en **Inicio** o se abre correctamente.

## Instalar VLC media player mediante descarga

1. Visita la [página oficial de VLC](https://www.videolan.org/vlc/).
2. Pulsa **Descargar VLC** y abre el instalador descargado.
3. Sigue el asistente con las opciones predeterminadas.
4. Comprueba que VLC aparece en **Inicio** o se abre correctamente. VLC será la aplicación que desinstalarás al final.

## Tarea 1. Consultar las aplicaciones instaladas

1. Abre **Inicio > Configuración > Aplicaciones > Aplicaciones instaladas**.
2. En **Ordenar por**, selecciona **Fecha de instalación** y muestra primero las aplicaciones más recientes. Maximiza la ventana para que quepan en pantalla.
3. Comprueba que aparecen **Microsoft To Do**, **Spotify**, **TeamViewer**, **7-Zip**, **Google Chrome** y **VLC media player**. Si no están todas a la vista, ajusta el orden y la posición de la lista hasta que se vean juntas.
4. Haz una única captura donde se distingan los nombres de las seis aplicaciones en la lista. Guárdala como `Tarea 1.jpg`.

## Tarea 2. Desinstalar VLC

1. En **Configuración > Aplicaciones > Aplicaciones instaladas**, busca `VLC`.
2. Abre el menú de opciones **…** junto a **VLC media player**, selecciona **Desinstalar** y confirma.
3. Vuelve a buscar `VLC` y comprueba que ya no aparece en la lista. No desinstales las demás aplicaciones.
4. Haz una captura donde se vea que la búsqueda no encuentra VLC o que ya no aparece en la lista. Guárdala como `Tarea 2.jpg`.

### Entrega

Entrega únicamente estas dos capturas:

- `Tarea 1.jpg`: muestra las seis aplicaciones instaladas antes de desinstalar VLC.
- `Tarea 2.jpg`: muestra que VLC ya no aparece entre las aplicaciones instaladas.
