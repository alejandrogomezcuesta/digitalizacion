## Resumen del vídeo: ¿Cómo funciona un PC y qué hace cada pieza?

Este vídeo explica de forma clara y accesible el funcionamiento interno de un ordenador, utilizando analogías sencillas para describir el papel específico de cada componente de hardware.

### 1. Procesador (CPU)
* **Función:** Es el «cerebro» del ordenador.
* **Detalles:** Se encarga de ejecutar instrucciones, realizar cálculos matemáticos y lógicos, y coordinar la comunicación entre los demás componentes.

### 2. Memoria RAM
* **Función:** Es la «mesa de trabajo» temporal del procesador.
* **Detalles:** 
  * Es una memoria ultrarrápida pero **volátil** (pierde los datos al apagar o reiniciar el sistema).
  * Almacena temporalmente los datos y programas que se están usando en el momento para que la CPU acceda a ellos al instante.

### 3. Almacenamiento (SSD / HDD)
* **Función:** Es el archivo permanente de la computadora.
* **Tipos:**
  * **HDD (Disco Duro Mecánico):** Alta capacidad a bajo coste, pero más lento.
  * **SSD / NVMe M.2 (Estado Sólido):** Memoria sin partes móviles, sumamente rápida.
* **Flujo de datos:** Los programas se guardan en el almacenamiento, se cargan a la memoria RAM cuando se abren y la CPU los procesa.

1. Los datos y el programa comienzan almacenados en el **dispositivo de almacenamiento**.
